# 业务目标
- 目标人群：高校学生和职场新人
- 教学目标：互联网行业的通识教育
- 教学难度：大概相当于北美本科低年级，和国内高中教育难度差不多、但范围广深度深
- 核心竞争力：通过优秀的教学水平把复杂的知识点讲简单，让用户更容易接受。

# 课程研发流程

1. 项目积累，包括开发文档、复盘、错误案例收集，等等
2. 整理成学习笔记和课程研发计划
3. 整理成系统性教程（dev）
4. 在内部会议和课程试讲（alpha测试）
5. 公开发表和拿到外部小范围试讲（beta测试）
6. 制作课件和视频上架、请测试用户试听（gamma测试）
7. 定稿上架（release）

注意：内部培训作为课程研发的alpha环节。这样可以集中管理教学，提高课程质量和实际应用导向，进而提高效率。

# 教学体系设计

主要分为两个部分，**通识教育**和**一对一培养**。

通识教育的思路来源于北美Undergraduate Level的教育理念，其积累是用来上架到课堂APP的，因此是同一个体系的问题，即上面提到的流程。互联网公司所需要的通识教育包括：
- 负责人：项目管理
- 开发：各领域编程、软件工程、算法工程、数据工程
- 设计：交互设计
- 产品：用户调研、产品原型设计
- 运营：用户增长、客户关系管理
- All：数据分析（直觉感觉所有人都需要）

一对一培养主要用于内培，重点在于培养Graduate Level的**生产新知识**的能力，侧重于发现其长处、引导其发扬长处，最终让他可以作为我们团队在这个领域可以指导其他人的专家。
