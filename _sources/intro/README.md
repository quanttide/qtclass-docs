# 产品简介

量潮课堂APP旨在解决高校学生和职场新人在互联网技术领域“学什么”、“怎么学”、“和谁一起”的问题。

## 用户痛点

- **缺少优质教育资源**，由于高校培养计划和就业市场脱节、职业教育市场上缺少专业机构和培养计划，他们大多只能靠自己艰难地探索而进步困难。
- **缺少有效的学习方法**，这是由于国内高校教育在这方面的**系统性缺失**。
- **缺少同伴**，由于缺少交流而进一步加剧寻找学习方向、深入提高领域知识、了解行业前沿动态的困难。

## 产品特性

- 提供高质量的课程，提供实用且系统的培养计划。
- 提供配套的学习方法，通过产品机制设计（比如自动化工具、运营等）帮助用户建立和维护这套学习方法。
- 提供认真可靠的答疑和其他帮助，如果有必要可以提供结对学习、开发者社群和社区服务。

## 商业模式

愿意在在线课程投入的高校学生的付费意愿通常在数百到小几千元，有收入和有明确需求的职场新人付费意愿最高可以是高校学生的几倍。初步的定价水平打算在高校学生可以接受的水平，对职场新人提供增值服务（比如定制培养计划、一对一答疑等）来获得更高的收入。
